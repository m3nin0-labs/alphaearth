# Package index

## Indexing & search

Build the local tile index and query it.

- [`index()`](https://m3nin0-labs.github.io/alphaearth/reference/index-topic.md)
  : Index the AlphaEarth tile catalogue locally
- [`search()`](https://m3nin0-labs.github.io/alphaearth/reference/search.md)
  : Search AlphaEarth tiles

## Export

Turn search results into data cubes, GeoTIFFs or virtual rasters.

- [`as_cube()`](https://m3nin0-labs.github.io/alphaearth/reference/as_cube.md)
  : Export AlphaEarth tiles to a data cube format.
- [`download()`](https://m3nin0-labs.github.io/alphaearth/reference/download.md)
  : Download AlphaEarth tiles as local GeoTIFFs
- [`as_vrt()`](https://m3nin0-labs.github.io/alphaearth/reference/as_vrt.md)
  : Write AlphaEarth tiles as virtual rasters (VRT)
